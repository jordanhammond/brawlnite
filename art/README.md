# Art references

Drop images here to guide how things look in the game. Any format works: PNG, JPG, screenshots, drawings, or photos of drawings on paper.

| Folder | Put in here |
|---|---|
| `heroes/brickster/` | Brickster ideas |
| `heroes/zippy/` | Zippy ideas |
| `heroes/boomer/` | Boomer ideas |
| `heroes/barf-bush/` | Barf Bush ideas |
| `map/` | World ideas (Lava Volcano, Candy Land) |
| `pickups/` | Icons for 💪 ⚡ 🩹 🧥 |

## Tips
- Name files so they say what they show, e.g. `colors.png`, `face.jpg`, `helmet-idea.png`
- Optionally add a `notes.txt` next to the images, e.g. "make the leaves darker" or "he should have a cape"
- The game is blocky and low-poly, so Claude will turn the images into simple Roblox-style shapes and colours, not exact copies
