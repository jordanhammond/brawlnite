# 13 · Players (names and profiles) ✅

## Entering a name ✅
- ✅ You must enter a name before playing
- 🔧 The name screen appears on first launch and whenever "Change player" is pressed
- 🔧 Names can be 1–12 characters long. Letters, numbers, spaces, `-` and `_` are allowed.
- 🔧 Existing players appear as big buttons, so a kid can tap their name instead of typing it
- 🔧 Press Enter or **▶ LET'S GO** to continue
- 🔧 The last player is remembered, so next time the game opens straight to the menu as them

## Each player has their own progress 🔧
- Wins, games, eliminations, and **unlocked heroes** are saved **per player**
- Everything is saved in this browser on this device (local storage)
- Migration: wins saved before profiles existed go to the **first** player created on that device
- `?resetwins` resets only the **current** player

## Change player ✅
- ✅ A "👤 Change player" button on the main menu goes back to the name screen
- 🔧 There's no delete button yet (see 11-future-ideas)
