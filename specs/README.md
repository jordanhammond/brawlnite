# BrawlNite: Specs

✅ 2026-10-03: renamed from "Bloknite" to **BrawlNite** (the project folder is still `bloknite/`).

A battle royale game for the browser, built by Jordan and the boys.

**One-line pitch:** characters that look like Roblox, abilities like Brawl Stars, and gameplay like Fortnite.
